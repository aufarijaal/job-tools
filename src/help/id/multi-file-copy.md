# Copy Files to a Folder

## Tentang fitur ini
Cari file berdasarkan nama di dalam folder sumber, pilih file yang dibutuhkan, lalu salin semuanya ke folder tujuan sekaligus.

## Cara pakai
1. Masukkan satu atau lebih nama file yang ingin dicari (satu nama per baris) di kolom **File Names**.
2. Pilih **Source Folder** — folder tempat pencarian dilakukan.
3. Pilih **Destination Folder** — folder tujuan hasil salinan.
4. Klik **Search Files** — file yang ditemukan akan ditampilkan beserta ukuran dan tipenya.
5. Tinjau hasilnya:
   - File yang **ditemukan** ditampilkan dengan kotak centang. Centang atau hapus centang tiap file, atau gunakan **Select All / Deselect All**.
   - File yang **tidak ditemukan** ditampilkan terpisah sebagai referensi.
6. Klik **Copy Selected Files** untuk menyalin semua file yang dicentang ke folder tujuan.

## Ringkasan hasil
Setelah proses selesai, ringkasan ditampilkan berisi:
- Jumlah file yang **berhasil disalin**.
- File yang **gagal**, beserta alasannya.

## Catatan
- Pencarian mencocokkan nama file secara persis (tidak membedakan huruf besar/kecil) di dalam folder sumber dan sub-foldernya.
- Jika file dengan nama yang sama sudah ada di folder tujuan, file tersebut akan ditimpa.
- Panel pratinjau di bagian bawah memungkinkan Anda melihat isi file yang ditemukan sebelum menyalinnya.
