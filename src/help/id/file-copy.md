# Copy File

## Tentang fitur ini
Fitur ini dipakai untuk menggandakan satu file menjadi banyak file sekaligus.
Anda bisa menyiapkan beberapa pekerjaan, lalu menjalankannya satu per satu otomatis.

## Istilah sederhana
- **Plan**: satu pengaturan pekerjaan copy.
- **Queue**: daftar pekerjaan yang menunggu dijalankan.
- **Run All Plans**: jalankan semua pekerjaan yang masih menunggu.

## Cara pakai
1. Isi lokasi file sumber dan folder tujuan.
2. Tambahkan awalan/akhiran nama file jika diperlukan.
3. Isi nama file hasil (satu nama per baris).
4. Klik **Create New Copy Plan**.
5. Jalankan dengan **Run** atau **Run All Plans**.
6. Lihat status dan catatan hasil proses.

## Catatan
- Anda bisa mengaktifkan opsi membuat folder tujuan otomatis.
- Jika ada yang gagal, alasannya akan ditampilkan.
