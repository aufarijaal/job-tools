# Beranda

## Tentang halaman ini
Beranda adalah halaman awal aplikasi. Dari sini, Anda bisa menuju ke semua menu dengan lebih mudah.

## Cara pakai
1. Buka aplikasi.
2. Lihat menu di sisi kiri.
3. Klik menu yang ingin digunakan.
4. Kapan saja, Anda bisa kembali ke Beranda.

## Saran
- Jika baru pertama kali pakai, biarkan menu kiri tetap terbuka.
- Mulai dari Beranda agar tidak bingung saat pindah fitur.
