# Powerful Text Editor

## Tentang fitur ini
Fitur ini adalah area menulis teks biasa.
Cocok untuk catatan, draft, atau daftar kerja harian.

## Yang bisa dilakukan
- Ubah tema tampilan (gelap/terang).
- Ubah ukuran huruf.
- Aktifkan atau matikan Word Wrap.
- Aktifkan atau matikan Minimap.
- Salin isi teks dengan tombol **Copy**.
- Kembalikan isi awal dengan tombol **Reset**.
- Buka **Help** untuk melihat shortcut keyboard.
- Lihat jumlah baris, kata, dan karakter secara langsung.

## Cara pakai
1. Tulis atau tempel teks Anda.
2. Atur tampilan agar nyaman dibaca.
3. Gunakan **Copy** jika ingin menyalin isi.
4. Gunakan **Reset** jika ingin kembali ke teks awal.

## Catatan
- Editor ini hanya untuk teks biasa. Tidak digunakan untuk menulis atau mengedit kode program.
