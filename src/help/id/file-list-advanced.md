# Multiple File Opener

## Tentang fitur ini
Fitur ini membantu mencari banyak file sekaligus dalam satu folder.
Hasil akan dipisah menjadi file yang ketemu dan tidak ketemu.
Anda bisa memilih apakah pencarian masuk sampai subfolder terdalam atau tidak.

## Yang perlu diisi
- **File Names**: isi daftar nama file, satu nama per baris.
- **Search Directory**: folder tempat pencarian dimulai.
- **Search Mode**: pilih **Contains search**, **Starts with search**, atau **Ends with search** dengan radio button.
- **Search deeper into subfolders (recursive)**: centang jika ingin ikut mencari ke subfolder.
- **Copy Found Format**: pilih **Numbered + type + name**, **Name only**, atau **Full path**.

## Cara pakai
1. Tempel daftar nama file.
2. Isi folder pencarian.
3. Pilih mode pencarian.
3. Opsional: centang recursive untuk pencarian ke folder yang lebih dalam.
3. Klik **Search Files**.
4. Cek hasil di bagian **Found** dan **Not Found**.
5. Pilih format salin untuk file ketemu, lalu salin hasil dengan tombol **Copy** yang tersedia.
6. Jika ingin, pilih file tertentu lalu klik **Open Selected**, atau klik **Open All Files**.

## Catatan
- Nama file bisa tetap ditemukan meski Anda tidak menulis ekstensi.
- Maksimal file yang bisa dibuka sekaligus adalah 10 file, supaya PC tidak melambat atau hang.
- Jika folder sangat besar, proses pencarian bisa lebih lama.
