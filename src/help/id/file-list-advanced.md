# File List Advanced

## Tentang fitur ini
Fitur ini membantu mencari banyak file sekaligus dalam satu folder.
Hasil akan dipisah menjadi file yang ketemu dan tidak ketemu.

## Yang perlu diisi
- **File Names**: isi daftar nama file, satu nama per baris.
- **Search Directory**: folder tempat pencarian dimulai.

## Cara pakai
1. Tempel daftar nama file.
2. Isi folder pencarian.
3. Klik **Search Files**.
4. Cek hasil di bagian **Found** dan **Not Found**.
5. Jika perlu, salin hasil dengan tombol **Copy** yang tersedia.
6. Jika ingin, klik **Open All Files** untuk membuka semua file yang ketemu.

## Catatan
- Nama file bisa tetap ditemukan meski Anda tidak menulis ekstensi.
- Jika folder sangat besar, proses pencarian bisa lebih lama.
