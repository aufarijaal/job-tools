# File List

## Purpose
File List displays the contents of a folder path and lets you copy the result.

## Inputs
- **Folder Path**: absolute path to a folder, for example `C:\\Users\\Name\\Documents`.

## How to use
1. Enter a valid folder path.
2. Click **List Files**.
3. Review files and folders shown in the result list.
4. Click **Copy List** to copy the output to your clipboard.

## Notes
- File size is shown for files.
- Errors are shown if the path is invalid or inaccessible.
