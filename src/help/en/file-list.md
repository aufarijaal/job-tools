# File Lister

## Purpose
File Lister displays the contents of a folder path, with optional deep (recursive) scanning.
You can copy the result.

## Inputs
- **Folder Path**: absolute path to a folder, for example `C:\\Users\\Name\\Documents`.
- **Search deeper into subfolders (recursive)**: optional checkbox to include nested folders.
- **Copy Format**: choose **Numbered + type + name**, **Name only**, or **Full path**.

## How to use
1. Enter a valid folder path.
2. Optional: enable recursive search if files may be inside nested folders.
2. Click **List Files**.
3. Review files and folders shown in the result list.
4. Choose copy format and click **Copy List** to copy the output to your clipboard.

## Notes
- File size is shown for files.
- Errors are shown if the path is invalid or inaccessible.
