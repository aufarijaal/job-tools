# Home

## Purpose
The Home page is the main entry point of Job Tools. It gives a quick overview and directs you to all available tools from the sidebar.

## How to use
1. Open the app.
2. Use the left menu to select a tool.
3. Return to Home anytime to navigate to another page.

## Tips
- Keep the sidebar expanded if you are new to the app.
- Use this page as a starting point before running any file operation.
