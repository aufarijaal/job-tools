# Powerful Text Editor

## Purpose
Powerful Text Editor is a plain-text workspace for writing notes, drafts, and structured text.

## Features
- Theme switch (Dark/Light)
- Font size control
- Word wrap toggle
- Minimap toggle
- Copy content
- Reset to starter text
- Shortcut Help modal
- Live counters (lines, words, characters)

## How to use
1. Write or paste your text.
2. Adjust display settings for readability.
3. Use **Copy** to move content to clipboard.
4. Use **Reset** to restore default template.
5. Open **Help** to learn editor shortcuts.

## Notes
- This is a plain text editor. It is not meant for writing or editing program code.
