# File List Advanced

## Purpose
File List Advanced searches many file names inside one directory tree and separates found/not found results.

## Inputs
- **File Names**: one keyword or name per line.
- **Search Directory**: root folder used for recursive search.

## How to use
1. Paste file names (one per line).
2. Enter the search directory path.
3. Click **Search Files**.
4. Review **Found** and **Not Found** groups.
5. Use **Copy Found**, **Copy Not Found**, or **Copy Complete Report** as needed.
6. Optional: click **Open All Files** for found results.

## Notes
- Search is flexible and can match names without extension.
- Large folders may take more time to scan.
