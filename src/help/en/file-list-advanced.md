# Multiple File Opener

## Purpose
Multiple File Opener searches many file names inside a directory and separates found/not found results.
You can choose whether to search deeper into subfolders.

## Inputs
- **File Names**: one keyword or name per line.
- **Search Directory**: root folder used for search.
- **Search Mode**: choose **Contains search**, **Starts with search**, or **Ends with search**.
- **Search deeper into subfolders (recursive)**: optional checkbox.
- **Copy Found Format**: choose **Numbered + type + name**, **Name only**, or **Full path**.

## How to use
1. Paste file names (one per line).
2. Enter the search directory path.
3. Choose the search mode.
3. Optional: enable recursive search for nested folders.
3. Click **Search Files**.
4. Review **Found** and **Not Found** groups.
5. Choose **Copy Found Format**, then use **Copy Found**, **Copy Not Found**, or **Copy Complete Report** as needed.
6. Optional: select specific found files and click **Open Selected**, or click **Open All Files**.

## Notes
- Search is flexible and can match names without extension.
- You can open a maximum of 10 files at once to reduce risk of PC slowdown or hang.
- Large folders may take more time to scan.
