# Copy File

## Purpose
Copy File lets you create multiple copy plans and run them as a queue.

## Main concepts
- **Plan**: one copy job configuration.
- **Queue**: list of pending plans.
- **Batch run**: execute all pending plans sequentially.

## How to use
1. Fill source file path and output directory.
2. Add optional prefix/suffix.
3. Enter output file names (one per line).
4. Click **Create New Copy Plan**.
5. Run with **Run** (single plan) or **Run All Plans**.
6. Monitor status and logs.

## Notes
- You can enable automatic output directory creation.
- Completed/failed plans keep execution details for review.
