# Copy Files to a Folder

## Purpose
Search for files by name inside a source folder, select the ones you need, and copy them all into a single destination folder at once.

## How to use
1. Enter one or more file names to search for (one per line) in the **File Names** box.
2. Select the **Source Folder** to search in.
3. Select the **Destination Folder** where the files will be copied.
4. Click **Search Files** — matching files are listed with their size and type.
5. Review the results:
   - **Found** files are shown with a checkbox. Tick or untick individual files, or use **Select All / Deselect All**.
   - **Not Found** files are listed separately for reference.
6. Click **Copy Selected Files** to copy every ticked file to the destination folder.

## Result summary
After copying, a summary shows:
- How many files were **copied successfully**.
- Any files that **failed**, with the reason.

## Notes
- The search looks for exact file-name matches (case-insensitive) inside the source folder and its sub-folders.
- If a file with the same name already exists in the destination, it will be overwritten.
- A preview panel at the bottom lets you view the contents of any found file before copying.
